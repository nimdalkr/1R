가상 상품이나 추정 치수를 승인하지 않습니다. 최대 200개 구매 옵션을 검수하고 관리하세요.

0/ 200 옵션미검수 후보는 추천·검색에서 제외
API 연결과 상품 검수는 별개입니다. API는 치수를 제공하지 않습니다. 후보를 가져온 뒤 정확한 옵션, 제조사·판매자 표기 규격, 판매 상태를 직접 확인하세요. 이 화면의 수정은 서버에 자동 저장되지 않습니다.
연결 검증 전

01. 후보 수집

검색 순위와 베스트 포함 여부는 판매량 순위가 아닙니다.

자동 대량 수집·자동 승인은 없습니다. 검색 후보 최대 10개, 베스트 후보 20개를 1회 호출합니다. 호출 예산 기본값은 검색·베스트 합산 시간당 8회입니다.

02. 검수 대기 · 카탈로그

검수할 상품을 선택하세요

쿠팡 API 후보를 가져오거나 정확한 상품 옵션을 직접 입력할 수 있습니다. API 키는 Vercel 환경변수 또는 로컬 .env.local에만 등록합니다.

03. 공개 카탈로그 내보내기

검수 대기는 제외합니다. catalog.json을 내보낸 뒤 npm run catalog:import -- 파일경로로 반영하고 커밋·재배포하세요. 재확인 필요·중지 상태는 데이터에 남지만 추천에서 제외됩니다.

실사·설치 보장 서비스가 아닙니다. 규격 근거, 옵션의 동일성, 확인 날짜가 없으면 공개할 수 없습니다. 운영자가 입력한 출처와 검수 내용은 코드 저장소의 변경 이력으로 관리합니다.
