# 1R

한국 원룸·오피스텔을 빠르게 배치해 보는 브라우저 기반 2D·3D 인테리어 플래너입니다.

## 현재 기능

- 원룸·오피스텔·1.5룸 등 보편적인 시작 템플릿 20종
- 2D 평면 / 간단한 3D 보기 전환
- 가구 드래그 이동, 90도 회전, 삭제, 크기·높이 수정
- 침대, 일자/ㄱ자 책상, 의자, 소파, 옷장, 책장, 행거, 카트, 박스, 모니터, PC, 노트북, 스탠바이미, 파티션, 러그 추가
- 브라우저 LocalStorage 자동 저장
- JSON 내보내기 / 불러오기
- 별도 서버·외부 라이브러리 없이 `index.html` 단독 실행

## 시작하기

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. Vercel 같은 정적 호스팅에도 그대로 배포할 수 있습니다.

## 데이터 원칙

프로젝트 데이터는 기본적으로 사용자 브라우저에만 저장됩니다. 템플릿 치수는 특정 건물의 실측 도면이 아니라 흔한 원룸 구조를 단순화한 시작값이므로 실제 집의 치수에 맞게 수정해야 합니다.

개인 방 사진 등 개인 참고 이미지는 공개 저장소에 포함하지 않습니다.

## 이름

**1R** — One Room, Your Way.
