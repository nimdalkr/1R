- `npm test`: **78개 통과**, 실패/생략 0개.

- `git diff --check`: 통과.

Node 테스트에는 실제 로컬 HTTP 서버를 실행해서 정적 파일·API 라우팅·비공개 파일 접근 차단을 확인한 테스트가 포함됩니다. 쿠팡 API 응답은 테스트 대역으로 처리했습니다.

현재 실행 환경의 Chromium은 로컬 HTTP URL 탐색을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단합니다. 브라우저 보안 정책을 변경하지 않았습니다. 대신 동일한 소스 JavaScript/CSS를 메모리에 로드하고 API·localStorage를 명시적인 테스트 대역으로 바꾼 오프라인 컴포넌트 테스트를 실행했습니다. **일반 HTTP 브라우저 E2E가 통과했다는 뜻은 아닙니다.** 일반 환경용 테스트는 `tests/browser_acceptance.py`에 제공합니다.
